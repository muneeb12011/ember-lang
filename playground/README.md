# The Ember website

A static website about Ember that runs the real compiler in the browser: `src/main.cpp` compiled to WebAssembly
with Emscripten. Five pages:

| Page | What it is |
|---|---|
| `index.html` | Home: a live demo that sends a program through every compiler stage, an annotated program, the six compiler stages, and how Ember is tested |
| `tour.html` | Twelve short lessons, each with a program you can edit and run |
| `play.html` | The playground: write a program and see its IR, optimized IR, x86-64 and output |
| `inside.html` | One program followed through the whole compiler, with real compiler output, plus the GC, testing and benchmarks |
| `reference.html` | The language reference |

Nothing compiles or runs until the visitor presses Run. Programs run on the compiler's reference interpreter
(`--interp`) in a web worker, and one that runs longer than 5 seconds is stopped.

## Layout

| Path | What it is |
|---|---|
| `pages/` | the page sources; the build fills in the shared head, header and footer |
| `tour/*.md` | the lessons: prose, then the lesson's program in the last ember code block |
| `examples/*.em` | the playground's example programs |
| `content/reference.md` | the language reference |
| `src/web_main.cpp`, `src/runner.js` | the browser entry point for the compiler, and the code that runs one compile |
| `site/` | the built website, ready to deploy: pages, `css/`, `js/`, `fonts/`, `data/`, `embc.js`, `embc.wasm` |

## Build

From the repository root, after `make`:

```
sh playground/build.sh --pages   # pages, lessons and examples only (needs python3 and python3-markdown)
sh playground/build.sh           # also rebuild the compiler for the browser (needs Emscripten: sudo apt install emscripten)
```

The Inside page's IR and assembly are generated by the native `./embc` during the build, so they always match
the compiler.

## Run and deploy

Locally: `cd playground/site && python3 -m http.server 8000`, then open http://localhost:8000.

On Vercel: import the repository and set **Root Directory** to `playground/site`, with no build command. Every
push to `main` redeploys.
